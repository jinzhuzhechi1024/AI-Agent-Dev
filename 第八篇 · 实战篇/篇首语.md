## 第八篇 · 实战篇 —— 从零构建自定义 Agent

> 理论到此为止，现在从零开始构建完整的 Agent 系统

前七篇我们完成了从概念到工程的完整知识体系建设：

- **第一篇**（第1-3章）建立认知：Agent是什么、LLM如何作为大脑、技术栈如何选
- **第二篇**（第4-8章）掌握四大工程范式：Prompt工程、Context工程、Loop工程、Harness工程
- **第三篇**（第9-13章）理解安全执行：沙箱、MCP协议、Skills系统、Rule与Hooks、Sub-Agent
- **第四篇**（第14-16章）运用设计模式：流程控制、交互协作、稳健安全
- **第五篇**（第17-20章）架构多Agent系统：架构模式、通信协议、协作策略、框架实战
- **第六篇**（第21-23章）深度解读三大开源框架：OpenClaw、Hermes Agent、Codex CLI
- **第七篇**（第24-26章）工程化与安全：评估测试、可观测性成本、生产部署安全

如果你一路读到这里，你已经具备了构建生产级Agent的全部理论知识。但"知道"和"做到"之间有一道鸿沟——本篇就是跨越这道鸿沟的桥梁。

本篇包含三个完整实战案例，从不同维度展示Agent的构建过程：

**第27章 从零搭建自定义Agent**——构建一个代码助手Agent。从需求定义到架构设计，从Harness构建到Agent Loop实现，从评估调优到经验总结。这是"从零开始"的完整过程，把第二篇到第三篇的所有概念（Context Engineering/Loop工程/Harness工程/MCP/Skills/Hooks/沙箱/Sub-Agent）串联成一个可运行的系统。

**第28章 企业知识增强助手**——构建一个企业内部知识问答Agent。核心是RAG+Agent的融合，解决企业知识库的权限控制、多轮对话、多数据源集成。这是企业场景最常见的Agent形态。

**第29章 自动化运维Agent**——构建一个从"监控感知"到"诊断推理"到"执行操作"的运维Agent。核心是安全边界——Agent能自主操作生产系统，但必须在人机协作的框架内运行。A2A协议在多Agent协作处理复杂故障中的应用也会在本章展示。

三个案例的共同特点：**每一章都呼应前面多个章节的概念**，让你看到理论知识如何组装成实际系统。这不是"教程"——教程只教"怎么做"；这是"工程实录"——记录"为什么这么做、什么有效、什么是坑"。

> 比喻：前七篇是"造一辆车的全部零件和图纸"——发动机（LLM）、底盘（Harness）、方向盘（Loop）、安全气囊（沙箱/护栏）、导航仪（Context Engineering）。第八篇是"把零件组装成一辆能跑的车"——三个案例就是三辆不同用途的车：代码助手是"跑车"（快和准）、知识助手是"商务车"（稳和安全）、运维Agent是"工程车"（强和可控）。
