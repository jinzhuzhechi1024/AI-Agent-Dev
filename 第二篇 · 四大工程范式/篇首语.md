## 第二篇 · 四大工程范式 —— 从"说什么"到"怎么做事"

> 篇首语：Prompt、Context、Loop、Harness——四层递进，嵌套而非并列

---

第一篇我们建立了 Agent 的心智模型：Agent = Model + Harness，LLM 有四个硬伤，Harness 六大组件补这些硬伤。但 Harness 不是一个扁平的"组件集合"——它有层次，有递进关系，有从简单到复杂的演进脉络。

这一篇，我们讲透 Agent 工程的四大范式：

- **L1 Prompt Engineering**：说什么（表达级）——怎么把任务表达清楚
- **L2 Context Engineering**：看到什么（推理级）——怎么管理模型每次推理时看到的信息
- **L3 Loop Engineering**：怎么转（循环级）——怎么设计 Agent 的感知-行动循环
- **L4 Harness Engineering**：在什么环境里做事（系统级）——怎么构建让 Agent 可靠工作的完整系统

这四层是**嵌套**关系，不是并列：Harness 包含 Loop，Loop 包含 Context，Context 包含 Prompt。每一层解决不同维度的问题，不能跳层——你不能在没有搞清楚 Context 的情况下直接做 Harness，就像你不能在没有地基的情况下直接盖屋顶。

本篇是理论主线——讲透"What"和"Why"。第三篇是实践主线——展开 Harness 的"How"（沙箱、MCP、Skills、Rule/Hooks、Sub-Agent）。

> 💡 比喻：四大工程范式就像盖楼的四层——地基（Prompt）→框架（Context）→楼层（Loop）→装修（Harness）。你不会先装修再打地基，也不会跳过框架直接盖楼层。每一层都是下一层的基础。
