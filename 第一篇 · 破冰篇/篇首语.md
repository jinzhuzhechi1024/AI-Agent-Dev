# 第一篇 · 破冰篇 —— Agent 的本质与心智模型

> 在写第一行 Agent 代码之前，先搞清楚 Agent 到底是什么。

---

如果你要在一片未知的土地上建一座城市，你不会第一天就开始打地基。你会先爬上最高的山，看看地形，搞清楚东南西北，弄明白哪里是河流、哪里是悬崖、哪里适合建城。

这一篇就是那座山。

在接下来的三章里，我们要回答三个最基本的问题：

- **Agent 到底是什么？** 它和聊天机器人有什么本质区别？（第 1 章）
- **LLM 作为 Agent 的"大脑"，到底能做什么、不能做什么？**（第 2 章）
- **要开发一个 Agent，有哪些工具和框架可用？**（第 3 章）

这三章不写一行代码。因为在你还没搞清楚"Agent 是什么"之前写的每一行代码，都可能是错的。

> 💡 比喻：这一篇像考驾照前的理论课。你不会在不知道油门和刹车区别的情况下就上路，同理，你也不该在不理解 Agent 本质的情况下就开始写 Agent。
